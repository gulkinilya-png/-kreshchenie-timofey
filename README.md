# Сайт-приглашение на крещение Тимофея

Сайт обновлён: **4 ноября 2026 года**, сбор гостей в **14:30**. После крещения — празднование в доме по адресу: **Коммунарка, посёлок Газопровод** (без маршрута к дому, как просили).

## Что внутри
- `index.html` — адаптивный сайт-приглашение;
- `assets/` — фотографии Тимофея и арендованного дома;
- `server.js` — сервер формы, отправляющий ответы в Telegram;
- `render.yaml` — настройки для развёртывания на Render.

## Как получить красивую ссылку
Я подготовил проект для размещения на Render. Саму публичную ссылку нельзя выпустить из чата без доступа к вашему аккаунту хостинга, но после развёртывания Render выдаст ссылку примерно такого вида: `https://kreshchenie-timofey.onrender.com`. Доступность имени зависит от того, свободно ли оно.

1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки.
2. Создайте аккаунт на Render и выберите **New → Blueprint**, подключив репозиторий с `render.yaml`.
3. В настройках сервиса добавьте переменные окружения `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` (инструкция ниже).
4. После успешного развёртывания Render покажет публичную HTTPS-ссылку. Её можно отправлять гостям.

## Настройка Telegram-уведомлений
Важно: бот не может сам начать личный диалог с пользователем. Сначала нужно создать бота и открыть с ним чат.

1. В Telegram откройте `@BotFather`, создайте бота командой `/newbot` и скопируйте токен.
2. Откройте чат с новым ботом и нажмите **Start** или отправьте `/start`.
3. Получите личный chat ID: откройте в браузере `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates` после отправки `/start`. В ответе найдите `message.chat.id`.
4. В настройках сервиса Render укажите:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather;
   - `TELEGRAM_CHAT_ID` — ваш личный chat ID.
5. После этого протестируйте форму на опубликованном сайте. При каждом ответе бот пришлёт вам имя гостя и его выбор.

**Не публикуйте токен бота** в HTML, браузерном JavaScript, публичных сообщениях или репозитории. Добавляйте его только в защищённые переменные окружения хостинга.

## Проверка перед отправкой гостям
- Убедитесь, что уведомление пришло в Telegram.
- Если хотите, пришлите точный адрес коттеджа позднее — его можно добавить отдельной строкой без кнопки маршрута.
